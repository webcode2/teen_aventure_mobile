1. Executive Summary & Vision

The Teen Quest & Dual Quiz Engine is the dedicated discipleship and active learning 
component of the ASK Hub ecosystem designed specifically for teenagers, Sunday school 
teachers, church leaders, and parents.

It combines structured weekly Scripture lessons with interactive, server-evaluated 
quizzes in two formats:
1. Multiple-Choice Objective Quizzes (OBJS)
2. Interactive Cross Scramble Word Puzzles (SCRAMBLE)

The platform guarantees strict content governance (only platform App Managers can author 
or modify quest content; Teachers can only activate live quizzes during class), live 
in-class activation, and role-aware leaderboard privacy blurring.

2. Stakeholder User Roles & Security Boundaries

Role                   Scope & Permissions in Teen Quest Engine
--------------------------------------------------------------------------------
App Manager            Platform Administrator. Has EXCLUSIVE authority to create, 
                       update, publish, and delete Teen Quest weekly content, 
                       objective quiz questions, and Cross Scramble word banks.

Teacher / Chaperone    Assigned to a specific church class. 
                       - CANNOT create, edit, or delete quest content.
                       - CAN ONLY activate/deactivate quizzes (OBJS, SCRAMBLE, BOTH) 
                         for their assigned class when gathering live.
                       - Sees full unblurred class leaderboards.

Children's Church Lead Manages church classes, assigns teachers, approves student 
                       class enrollments. Sees full unblurred class leaderboards.

Pastor / Nominee       Church oversight. Sees full unblurred class leaderboards.

Teenager (Student)     Participates via independent or parent-linked login. 
                       - Reads weekly quest content and scripture.
                       - Solves activated Objective & Cross Scramble quizzes.
                       - Views class leaderboard with classmates' names visible to 
                         foster healthy peer motivation.

Parent / Guardian      Monitors their teenager's progress. 
                       - Views class leaderboard with THEIR teenager unblurred and all 
                         other class members blurred for privacy safeguarding.

3. Backend Specifications (App 1 Engine)

3.1 Data Architecture (Prisma Schema)
- `TeenQuest`: Holds `weekNumber`, `title`, `scripture`, `lessonBody`, `objectiveQuiz` 
  (JSON array of questions, options, answerIndex), and `scrambleQuiz` (JSON array 
  of scrambled words, target answers, clues).
- `ClassQuizActivation`: Tracks teacher live quiz activations (`classId`, `questId`, 
  `quizType`: `OBJS` | `SCRAMBLE` | `BOTH`, `activatedByUserId`, `isActive`).
- `ScoreLedger`: Immutable points ledger recording `TEEN_QUEST_OBJS` (up to 50 pts) 
  and `TEEN_QUEST_SCRAMBLE` (up to 50 pts).

3.2 Core API Endpoints
- `GET /api/teen-quest/weeks`: List published Teen Quests.
- `GET /api/teen-quest/weeks/:weekNumber`: Fetch quest content and quiz payloads.
- `POST /api/teen-quest/class/:classId/activate`: Teacher live quiz activation 
  (Requires Teacher/Lead role for that class).
- `GET /api/teen-quest/class/:classId/active`: Check current active quiz status.
- `POST /api/teen-quest/submit-objs`: Server-side objective quiz evaluation.
- `POST /api/teen-quest/submit-scramble`: Server-side word-match scramble evaluation.
- `GET /api/teen-quest/class/:classId/leaderboard`: Role-aware leaderboard calculation.
- `POST/PUT/DELETE /api/teen-quest/admin/weeks`: Quest authoring (Requires App Manager).

4. Flutter Mobile Application Specifications (`mobile`)

4.1 Architecture & Tech Stack
- Framework: Flutter (Dart) cross-platform for iOS and Android.
- State Management: Riverpod / Provider for reactive UI updates.
- Networking: Dio / http client with bearer JWT token interception.
- Local Storage: Flutter Secure Storage for PIN/tokens and Hive for offline caching.

4.2 UI Screen Flow & Components
1. Teen Authentication & PIN Screen:
   - Supports independent email/password login or 4-digit PIN authentication.
2. Weekly Quest Feed & Reader Screen:
   - Interactive card carousel showing weekly Teen Quests.
   - Clean typography for Scripture readings, memory verses, and lesson breakdown.
3. Active Quiz Waiting & Status Card:
   - Real-time indicator showing if the Teacher has activated today's quiz (`OBJS`, 
     `SCRAMBLE`, or `BOTH`).
4. Objective Quiz Solver Component (OBJS):
   - Multi-question step progress bar, radio/card option pickers, immediate visual feedback.
5. Cross Scramble Word Solver Component (SCRAMBLE):
   - Interactive letter tile grid where teens drag or tap letters to unscramble target 
     Scripture words before submitting.
6. Class Leaderboard Screen:
   - Ranks class members by total weekly points.
   - Displays unblurred classmate names for Teen users.
   - Implements parent privacy view when accessed in Parent Mode.

5. Web Admin & Chaperone Dashboard Specifications (`admin`)

5.1 Tech Stack & UI Framework
- Framework: React + TypeScript + Vite.
- Styling: Modern CSS / Glassmorphism UI tokens.
- Router: React Router v6.

5.2 Component Breakdown
1. App Manager Quest CMS Builder (`/admin/quests`):
   - Form builder to add weekly Teen Quests.
   - Rich text editor for Scripture and lesson body.
   - Objective Question Builder: Add question text, 4 choices, select correct index, 
     assign points.
   - Cross Scramble Builder: Add target words, clues, and auto-scramble generator.
   - Authoring Guard: Restricts access exclusively to `APP_MANAGER` platform role.
2. Teacher Live Class Activation Panel (`/teacher/activate`):
   - Select assigned church class and current week's Teen Quest.
   - Toggle buttons: `Activate Objective Quiz`, `Activate Cross Scramble`, or `Activate Both`.
   - Single-click Deactivation button once class time concludes.
3. Live Leaderboard & Class Roster View (`/teacher/class-leaderboard`):
   - Live updating table showing participating students, completed quiz types, score, 
     and rank. Full unblurred names for Teachers and Church Leads.


================================================================================
6. Privacy, Safeguarding & Rule Safeguards

1. Strict Authorization Scoping:
   - Content authoring (Create/Update/Delete) is hard-locked to App Managers.
   - Teachers attempting to modify content receive `403 Forbidden ("App Manager only")`.
2. Live In-Class Co-Presence Guard:
   - Students can only submit quiz answers when their Teacher has explicitly set 
     `isActive = true` for their assigned class.
3. Leaderboard Privacy Blurring:
   - Parents viewing the class leaderboard see their own teen unblurred (`isMine: true`) 
     while other class members are blurred (`Participant #1`).
